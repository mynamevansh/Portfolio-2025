# 🌟 Portfolio Website - Vansh Pratap Singh Ranawat

A modern, responsive portfolio website showcasing my skills, projects, and experience as a Full Stack Web Developer. Built with vanilla HTML, CSS, and JavaScript to demonstrate clean code and design principles.

## 🚀 Live Demo

Visit the live portfolio: [https://portfolio-2025-xi-ten.vercel.app/](https://portfolio-2025-xi-ten.vercel.app/)

## ✨ Features

- **Responsive Design**: Fully responsive layout that works seamlessly across all devices
- **Dark/Light Mode**: Toggle between dark and light themes for comfortable viewing
- **Smooth Animations**: Scroll reveal animations and smooth transitions
- **Interactive UI**: Dynamic typing effect, skill bars, and hover effects
- **Contact Form**: Integrated EmailJS for direct email communication
- **Social Media Integration**: Quick links to LinkedIn, GitHub, Gmail, and Twitter

## 🛠️ Technologies Used

- **HTML5**: Semantic markup and structure
- **CSS3**: Custom styling, animations, and responsive design
- **JavaScript**: DOM manipulation, interactive features, and animations
- **Font Awesome**: Icon library for social media and UI icons
- **Typed.js**: Dynamic typing animation library
- **ScrollReveal.js**: Scroll animation library
- **EmailJS**: Email service integration for contact form

## 📦 Installation & Setup

1. Clone the repository:
```bash
git clone https://github.com/mynamevansh/Portfolio-2025.git
```

2. Navigate to the project directory:
```bash
cd Portfolio-2025
```

3. Open `index.html` in your browser or use a local server:
```bash
# Using Python
python -m http.server 8000

# Using Node.js (http-server)
npx http-server
```

4. Visit `http://localhost:8000` in your browser

## 🔧 Configuration

To customize the portfolio:

1. **Update Personal Information**: Edit `index.html` to change name, bio, and contact details
2. **Modify Styles**: Edit `css/style.css` to adjust colors, fonts, and layout
3. **Add Projects**: Update the projects section in `index.html`
4. **EmailJS Setup**: Replace the EmailJS credentials in the script tag with your own
